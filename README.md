# 📊 Ecommerce Sales Dashboard – Power BI

**Author: Varshitha Pavuluri**

## 📌 Project Overview

The Ecommerce Sales Dashboard is an interactive data visualization project developed using Microsoft Power BI. It provides valuable insights into e-commerce business performance by analyzing sales, profit, product categories, customer segments, geographical regions, and shipping methods.

The dashboard transforms raw sales data into meaningful visual insights, helping businesses monitor performance and make data-driven decisions.

## 🎯 Project Objectives

- Analyze overall e-commerce sales performance.
- Track Year-to-Date (YTD) sales, profit, quantity, and profit margin.
- Identify the top 5 and bottom 5 performing products.
- Compare sales across different product categories.
- Analyze regional sales performance.
- Understand customer segment contributions.
- Evaluate sales distribution based on shipping methods.

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)

- YTD Sales
- YTD Profit
- YTD Quantity
- YTD Profit Margin

### 2. Sales by Category

Analyzes sales performance across:
- Technology
- Office Supplies
- Furniture

### 3. Top 5 Products by YTD Sales

Identifies the five products generating the highest sales revenue.

### 4. Bottom 5 Products by YTD Sales

Highlights the five products generating the lowest sales revenue.

### 5. YTD Sales by Region

Visualizes sales distribution across:
- West
- East
- Central
- South

### 6. Sales by States

Displays geographical sales distribution across different states using a map visualization.

### 7. YTD Sales by Shipping Type

Analyzes sales distribution across different shipping methods.

### 8. Customer Segmentation

Provides sales insights based on:
- Consumer
- Corporate
- Home Office

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Extract the downloaded project files.
3. Install Microsoft Power BI Desktop.
4. Open `Ecommerce_Sales_Insights.pbix`.
5. Wait for the report to load.
6. Explore the dashboard using the available filters and visualizations.
